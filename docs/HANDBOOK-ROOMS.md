# คู่มือห้องเล่นโค้ดน้อย — ส่งมอบงาน + วิธีเพิ่มห้องใหม่ด้วยตัวเอง

เอกสารนี้เขียนให้ผู้ดูแลเว็บที่**ไม่ใช่คนเขียนโค้ดเดิม** อ่านแล้วเข้าใจได้ว่า:
ห้องเล่นมีกี่ห้อง อยู่ตรงไหนของโค้ด และจะเพิ่มห้องใหม่ 1 ห้องได้อย่างไร

## 1) สรุปตัวเลขล่าสุด

- **ห้องเล่นทั้งหมด: 11 ห้อง** (ห้องเดิม 5 + ห้องใหม่ 6) นับจากล็อบบี้ใน play.html
- ล็อบบี้แสดงการ์ดแบบ "ภาพนำ" — ไอคอนห้องใหญ่ + ดาว 1–3 ดวงตามคะแนนสูงสุด + ป้าย "✨ ห้องใหม่!" ถ้ายังไม่เคยเล่น
  (ตัวเลขสถิติ 🏆 ยังอยู่ในการ์ดแบบตัวเล็ก สำหรับผู้ปกครองอ่าน)
- ทุกห้องมี "องค์ประกอบภาษาภาพ" ช่วยเด็กที่ยังอ่านไทยไม่ออก (ดูหัวข้อ 2.1)
- บันทึกผลอยู่ใน localStorage ของเบราว์เซอร์ (คีย์เดียวกับระบบดาว: `kodnoi.v1`)

### 2.1) องค์ประกอบ "ภาษาภาพ" (สำหรับเด็กที่ยังอ่านไทยไม่ออก)

เว็บออกแบบให้ **สัญลักษณ์นำข้อความ** ทุกจุดที่เด็กต้องใช้ตัดสินใจ:

| องค์ประกอบ | หน้าที่ | อยู่ที่ |
|---|---|---|
| มาสคอตหน้าแบนเนอร์ | บอกว่า "น้องบอทกำลังพูดกับหนู" (CSS `.banner::before`) | ทุกห้องอัตโนมัติ |
| ✅ / 💪 ท้ายแบนเนอร์ | ผลลัพธ์ตอบถูก / ชวนลองอีกครั้ง (CSS `.banner.good::after`, `.banner.warn::after`) | ทุกห้องอัตโนมัติ |
| แถบวิธีเล่นแบบภาพ `.howto` | สรุปวิธีเล่นเป็นภาพ 3 ช่อง เช่น 🍎 ➜ 🧺 ➜ ✅ | `play.html` แต่ละห้อง (ใต้แบนเนอร์) |
| จุดความคืบหน้า `.goaldots` | ●●●○○ แทนข้อความ "ข้อที่ 3 / 8" | เรียก `KN.ui.dots(อิลิเมนต์, ปัจจุบัน, ทั้งหมด)` ใน logic ของห้อง |
| ไอคอนสะสม `KN.ui.icons()` | นับชัยชนะเป็นภาพ เช่น แครอท 🥕 ของห้องเขาวงกต | logic ของห้องเขาวงกต |
| ดาว 1–3 ดวงบนการ์ดล็อบบี้ | ความคืบหน้าของห้องนั้น (0 เล่น = ป้าย "✨ ห้องใหม่!") | `games-lobby.js` |
| จุดใต้ตัวเลข `.numdots` | ให้นับจุดเทียบจำนวนของได้ โดยไม่ต้องรู้ตัวเลข | ห้องตลาดนับของ |
| สัตว์บนบันไดดนตรี `.notebtn__ic` | จำเสียงเป็น "เสียงช้าง/เสียงกระต่าย" แทนชื่อโน้ต | ห้องบันไดดนตรี |
| ตัวอย่างของในตะกร้า `.basket__demo` | เห็นภาพตัวอย่างว่าอะไรอยู่กลุ่มไหน | ห้องแยกตะกร้า |

## 3) วิธีเพิ่มห้องเล่นใหม่ 1 ห้อง (ทำตาม 5 ขั้น)

ตัวอย่างนี้สมมติว่าจะเพิ่มห้อง "จับคู่เงา" (`shadow`) ให้เด็กจับคู่รูปกับเงา

### ขั้นที่ 1 · เพิ่มข้อมูลในทะเบียน `ROOMS`
เปิด `assets/js/games.js` ไปที่อาร์เรย์ `ROOMS` (อยู่ช่วงต้นไฟล์ ค้นคำว่า `var ROOMS`)
แล้วเติมบรรทัดใหม่ท้ายสุด:

```js
{ id: 'shadow', icon: '🕶️', name: 'จับคู่เงา', skill: 'สังเกต',
  desc: 'จับคู่รูปกับเงาให้ถูกต้อง',
  how: 'แตะเงาที่ตรงกับรูปด้านบน' }
```

> `id` ต้องเป็นตัวอักษรอังกฤษตัวเล็ก ไม่ซ้ำกับห้องอื่น ส่วนชื่อ/คำอธิบายใช้ภาษาไทยได้เลย

### ขั้นที่ 2 · เพิ่มปุ่มแท็บใน play.html
ใน `play.html` หา `<div class="tabs" ...>` แล้วเพิ่มปุ่มหนึ่งปุ่ม:

```html
<button class="tab" role="tab" data-tab="shadow" aria-selected="false"
        aria-controls="tab-shadow">🕶️ จับคู่เงา</button>
```

ค่า `data-tab` ต้องตรงกับ `id` ที่ใส่ไว้ในขั้นที่ 1

### ขั้นที่ 3 · เพิ่มแผงห้อง (panel) ใน play.html
เพิ่ม `<section>` ต่อจากแผงห้องอื่น โดยใช้รูปแบบเดียวกับห้องเดิม:

```html
<section class="panel" id="tab-shadow" role="tabpanel" aria-label="จับคู่เงา">
  <div class="stage">
    <div class="stage__head">
      <a class="backbtn" href="#lobby" data-back="lobby">🗺️ ล็อบบี้</a>
      <h3>🕶️ จับคู่เงา</h3>
      <span class="badge">สังเกต</span>
      <span class="goal"><span id="shCount">ข้อ 1 / 6</span> <span class="goaldots" id="shDots" aria-hidden="true"></span></span>
    </div>
    <p class="banner" id="shHint">แตะเงาที่ตรงกับรูปด้านบน</p>
    <!-- แถบวิธีเล่นแบบภาพ: ภาพ 2–3 ช่องคั่นด้วยลูกศร ➜ -->
    <div class="howto" aria-label="วิธีเล่นแบบภาพ">
      <span class="howto__g">🐼</span><i class="howto__arr">➜</i>
      <span class="howto__g">🖤</span><i class="howto__arr">➜</i>
      <span class="howto__g">✅</span>
    </div>
    <!-- วางองค์ประกอบของเกมตรงนี้ เช่น <div id="shBoard"></div> -->
  </div>
</section>
```

- `id` ของ section ต้องเป็น `tab-` + รหัสห้อง (เช่น `tab-shadow`)
- ห้ามลืมปุ่ม `backbtn` เพราะเป็นทางกลับล็อบบี้ที่เกณฑ์ตรวจรับกำหนด
- เกณฑ์ "แสดงวิธีเล่นก่อนเริ่ม": ใส่ข้อความวิธีเล่นไว้ใน `<p class="banner">` และ/หรือ `<p class="muted">`
- แนะนำให้มี `howto` (วิธีเล่นเป็นภาพ) และ `goaldots` (จุดความคืบหน้า) เหมือนห้องอื่นทุกห้อง
  โดยใน logic ของเกมเรียก `KN.ui.dots(document.getElementById('shDots'), ข้อปัจจุบัน, ข้อทั้งหมด)` ทุกครั้งที่เปลี่ยนข้อ

### ขั้นที่ 4 · เขียนตรรกะของเกม
เปิด `assets/js/rooms-extra.js` เพิ่มโค้ดท้ายไฟล์ (โครงเดียวกับห้องอื่น):

```js
/* ====== ห้อง 12 — จับคู่เงา ====== */
(function () {
  var KN = window.KN, ui = KN.ui, store = KN.store;
  var $ = ui.$;
  var board = document.getElementById('shBoard');
  if (!board) return;                       // กันหน้าอื่นโหลดไฟล์นี้แล้วพัง
  var score = 0;

  function newRound() { /* ...สร้างโจทย์ใหม่... */ }
  function onAnswer(ok) {
    if (ok) {
      score += 10;
      KN.audio.pop();
      store.addStars(1); KN.paintHud();
      // เมื่อผู้เล่นจบรอบสมบูรณ์ ให้บันทึกผลห้องนี้:
      store.recordPlay('shadow', score);
    }
  }
  newRound();
})();
```

หลักการบันทึกผล: **เรียก `store.recordPlay('shadow', คะแนน)` เมื่อผู้เล่นจบรอบ** (ไม่ใช่ตอนแตะครั้งเดียว)
ระบบจะเก็บ "คะแนนสูงสุด / จำนวนครั้ง / เวลาล่าสุด" ให้เอง และการ์ดในล็อบบี้จะอัปเดตเมื่อเข้าล็อบบี้ครั้งถัดไป

### ขั้นที่ 5 · ทดสอบ + อัปเดตเอกสารนี้
1. เปิด `play.html` แล้วตรวจ 5 เส้นทาง: ล็อบบี้ → ห้องใหม่ → เล่นจนจบรอบ → กลับล็อบบี้, สลับแท็บตรง ๆ, กดกลางเกม, ปิดหน้าแล้วเปิดใหม่ดูสถิติ
2. ย่อหน้าจอมือถือ (~375px) ตรวจว่าปุ่มไม่ล้นจอ
3. เพิ่ม 1 แถวในตาราง "รายการห้องทั้งหมด" ด้านบน และแก้เลขสรุปในหัวข้อ 1) ให้ตรง

## 4) ข้อควรระวังที่พบบ่อย

- **สร้างแผงแต่ไม่ขึ้น:** ตรวจว่า `id` ของ section ขึ้นต้นด้วย `tab-` และตรงกับ `data-tab` ของปุ่ม
- **จบรอบแล้วล็อบบี้ไม่ขึ้นสถิติ:** ต้องเรียก `store.recordPlay(...)` เมื่อจบรอบเท่านั้น และต้องใช้ `id` ห้องเดียวกับใน `ROOMS`
- **เขียน `goTab` เองในไฟล์ใหม่:** ไม่ต้อง เพราะ `games-lobby.js` มีไว้ให้แล้ว (เรียก `goTab('lobby')` ได้เลย)
- **เพิ่มห้องแล้วภาษาต่างประเทศหลุดเข้ามา:** ข้อความทุกจุดต้องเป็นภาษาไทย (ชื่อปุ่ม ข้อความชวน ป้าย aria-label) เพราะเว็บนี้ทำเพื่อเด็กไทย
